# C&C Online Tech Support Guides

![](assets/images/cnclogo.png)

### Introduction

Welcome to the technical support documentation project for C&C Online.

We are a dedicated volunteer-driven team of developers, enthusiasts, and zealous C&C fans committed to bringing online multiplayer functionality back to classic Command & Conquer titles. Our software restores online play using a custom backend infrastructure, providing network connectivity and online play features for these games that no longer have online support since Gamespy went down. The tools, patches, and backend infrastructure we've developed allow players to once again enjoy the multiplayer experience and command their armies in full glory to their heart's content. Our solution is designed to be as seamless and native-feeling as possible, integrating directly with the original game clients while preserving compatibility with various releases, including Retail, Steam, and EA, whilst also supporting mods where feasible.

This documentation serves as the central hub for technical support and troubleshooting resources. The linked guides are designed to help you resolve common problems and get back into enjoying these timeless games. We're going to cover topics such as:

* Installation and initial setup
* Online account configuration
* Network connectivity and NAT traversal issues
* Troubleshooting unexpected behavior
* Linux, Wine and Proton support

Each guide is written with both novice and advanced users in mind. Where possible, we’ve included screenshots, command-line examples, and detailed explanations of how our software interacts with the game and the network stack.

We will be continuously updating this documentation as our tools evolve and new edge cases arise. We recommend reading through the relevant guides carefully before reaching out for support. If you experience issues not covered in the provided materials, or if you believe you've found a bug in our tools, please join our community Discord or our support forum and create a tech-support ticket for further assistance.

Thank you for helping us keep the beloved C&C legacy alive — and welcome back, commander.
